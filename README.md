# AvisBoost

Landing page d'AvisBoost — la plateforme qui permet aux commerces d'envoyer une demande d'avis Google par e-mail en un clic, après chaque visite client.

## Stack

- [Vite](https://vite.dev/) + [React](https://react.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Framer Motion](https://motion.dev/)
- [Phosphor Icons](https://phosphoricons.com/)

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
